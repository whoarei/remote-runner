# Remote Runner v0.7.0

## 新功能

- **预置命令面板**：侧栏新增「预置命令」面板，可把常用远程命令保存为预置项（名称 + 命令 + console 模式 + 超时），双击即对当前选中的设备执行，无需每次手工输入。支持标题栏 ＋ 添加、右键编辑/删除（删除有确认）、面板折叠与「视图 → 预置命令面板」显隐开关。预置数据保存在本机，重启后保留；串口设备执行时自动使用合并输出（pty）。

## 验证范围

- 前端测试 65 项（含预置命令 normalize / 持久化 5 项新增用例）、TypeScript 检查、Vite 构建通过。
- 双击执行复用既有 `startRun` 链路（含未保存文件先保存、运行历史），未改动传输层，无硬件回归风险；面板交互与布局建议在桌面环境手动确认。

## 升级说明

- 安装包可通过应用内「更新」按钮直接升级；便携版请到发布页下载 `Remote.Runner_0.7.0_x64-portable.exe`。
- `latest.json` 与 `.exe.sig` 用于更新校验，无需手动打开。
