# Remote Runner v0.5.4

## 新功能

- **单实例运行**：应用同时只允许运行一个实例（基于官方 `tauri-plugin-single-instance`）。已运行时再次手动启动会唤起并聚焦已有主窗口；开机自启动项重复触发（`--minimized`）时静默退出、不弹窗打扰。避免多实例造成的串口占用冲突与运行历史/日志并发写入。

## 验证范围

- Rust 测试（85 项）、前端测试（58 项）、`cargo fmt --check`、TypeScript 检查、Vite 构建通过。

## 升级说明

- 安装包可通过应用内「更新」按钮直接升级；便携版请到发布页下载 `Remote.Runner_0.5.4_x64-portable.exe`。
- `latest.json` 与 `.exe.sig` 用于更新校验，无需手动打开。
