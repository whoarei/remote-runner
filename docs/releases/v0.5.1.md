# Remote Runner v0.5.1

## 改进

- 新建终端一步完成：点击控制台标签栏的「＋」直接弹出设备列表，点选设备立即打开终端，去掉了原来的下拉选择与确认按钮；串口设备在列表中显示「暂不支持终端」并置灰。

## 验证范围

- 前端测试（58 项）、TypeScript 检查、Vite 构建通过。
- 本次仅涉及前端交互，无串口 / SSH / WSL 传输行为变更。

## 升级说明

- 安装版可通过应用内「更新」按钮直接升级；便携版请从发布页面下载 `Remote.Runner_0.5.1_x64-portable.exe`。
- `latest.json` 与 `.exe.sig` 供应用更新验证使用，无需手动打开。
