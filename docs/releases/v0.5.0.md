# Remote Runner v0.5.0

## 新功能

- 文件编辑区支持多标签：标签内直接关闭（带未保存确认），每个标签独立的撤销历史、滚动位置与选区，`Ctrl+W` 关闭当前标签。
- 「运行」前自动保存所有未保存的标签，任一保存失败则不启动，避免远端运行到旧版本文件。
- 编辑器去掉独立工具条：有修改时状态栏显示可点击的「保存」（等价 `Ctrl+S`），无修改显示「已保存」；语言选择并入状态栏右侧。
- 文件编辑区可折叠为标签条，展开中的控制台自动占满释放的高度。
- 运行历史支持导出单条记录（含输出日志）、清空历史；每次运行的输出按 run 持久化到 `run_logs/`（2 MiB 上限，随历史清理）。
- 设备管理并入「文件」菜单，设备选择移至运行工具栏。

## 验证范围

- 前端测试（58 项）、TypeScript 检查、Vite 构建、Rust 全量测试通过。
- 未使用物理串口设备；串口行为仍以双工流模拟与本地 Shell 冒烟验证为准。

## 升级说明

- 安装版可通过应用内「更新」按钮直接升级；便携版请从发布页面下载 `Remote.Runner_0.5.0_x64-portable.exe`。
- `latest.json` 与 `.exe.sig` 供应用更新验证使用，无需手动打开。
