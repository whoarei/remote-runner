# Remote Runner v0.8.0

## 新功能

- **本机 Shell 直连**：新增 pwsh、PowerShell、cmd、MSYS2/Git Bash 及 Unix Shell 设备，可直接在本机工作区运行 Python、Shell 和命令，支持 PTY、pipe、交互输入、缩放、停止与超时。
- **终端与面板菜单**：工作区、运行控制台、终端和预置命令面板增加上下文菜单；新建终端设备列表显示连接目标、发行版、串口或 Shell 等详细信息。

## 修复

- 修复长设备列表弹出菜单可能超出窗口边界、内容被截断或无法滚动的问题。
- 修复 pwsh/MSYS2 本机终端启动后提示符出现在窗口中部的问题；启动光标现在正确位于左上角。

## 验证范围

- 前端测试、TypeScript 检查和 Vite 构建通过。
- Rust 格式检查及本机 Shell 相关单元测试通过；完整 Rust 测试按发布流程执行。
- 本机 Shell 的实际交互效果建议在 Windows 桌面环境中使用 pwsh、cmd 和 MSYS2/Git Bash 手动确认；没有可用串口硬件。

## 升级说明

- 安装包可通过应用内「更新」按钮直接升级；便携版请到发布页下载 `Remote.Runner_0.8.0_x64-portable.exe`。
- `latest.json` 与 `.exe.sig` 用于更新校验，无需手动打开。
