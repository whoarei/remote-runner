# Remote Runner v0.3.0

本版本新增应用更新功能，支持 Windows x64 安装版和便携版。

## 新增与改进

- 在「帮助 → 检查更新…」或关于窗口中检查新版本、查看更新说明。
- 安装版支持下载更新、显示进度、验证签名并启动安装程序，安装完成后重新打开应用。
- 便携版提供手动下载入口；检查或下载失败时也可前往发布页面更新。
- 升级前检查未保存文件和运行任务，避免升级中断工作；防止重复安装。
- 发布流水线统一版本号与锁文件，生成签名安装包和更新清单并检查资产完整性。

## 下载选择

- `Remote.Runner_0.3.0_x64-setup.exe`：Windows x64 安装包，推荐使用，支持后续应用内更新。
- `Remote.Runner_0.3.0_x64-portable.exe`：便携可执行文件，后续需手动替换。
- `latest.json` 与 `.exe.sig`：供应用更新验证使用，无需手动打开。

从尚未包含更新功能的旧版本升级，请先手动下载安装本版本。

## 验证说明

前端 41 项测试及生产构建通过；Rust 68 项测试通过，7 项需要指定 WSL 环境的测试按约定跳过。无 SSH/串口实物硬件验证；真实 Windows 覆盖安装与重启仍需在独立环境验收。
