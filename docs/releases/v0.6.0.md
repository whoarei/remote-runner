# Remote Runner v0.6.0

## 新功能

- **标题栏面板切换按钮**：在最小化按钮旁新增三个 VSCode 风格图标，分别控制左侧栏、控制台面板、右侧栏的显隐。侧栏显示在左侧时按右侧图标会将其移到右边，再按一次则整体隐藏（各面板的显隐设置保留，恢复时原样展示）；隐藏的侧栏按任意一侧图标即在该侧重新显示。当前生效的面板按钮会高亮显示。「视图」菜单同步新增「侧栏」勾选项。

## 验证范围

- 前端测试（62 项）、TypeScript 检查、Vite 构建通过。
- 面板切换为纯前端布局改动，标题栏按钮的视觉效果建议在桌面环境手动确认。

## 升级说明

- 安装包可通过应用内「更新」按钮直接升级；便携版请到发布页下载 `Remote.Runner_0.6.0_x64-portable.exe`。
- `latest.json` 与 `.exe.sig` 用于更新校验，无需手动打开。
