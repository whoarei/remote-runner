# Remote Runner v0.6.1

## 新功能

- **界面多语言（中文 / English）**：全部界面文案支持中英文双语。默认跟随系统语言（系统为中文显示中文，其余显示英文），可在「视图 → 语言」菜单手动切换为中文或 English，选择持久化保存，重启后生效。运行状态（准备中 / 同步中 / 运行中 / 已退出等）、面板标题、菜单、对话框、按钮、提示信息均已本地化。

## 验证范围

- 前端测试（60 项，含断言文案的用例固定中文环境）、TypeScript 检查、Vite 构建通过。
- 语言切换的即时生效与持久化、以及各对话框在新语言下的显示效果，建议在桌面环境手动确认。

## 升级说明

- 安装包可通过应用内「更新」按钮直接升级；便携版请到发布页下载 `Remote.Runner_0.6.1_x64-portable.exe`。
- `latest.json` 与 `.exe.sig` 用于更新校验，无需手动打开。
