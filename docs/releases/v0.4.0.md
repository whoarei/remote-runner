# Remote Runner v0.4.0

## 新功能

- 控制台面板支持多标签：保留运行控制台，并可同时打开多个独立终端。
- SSH 与 WSL 支持真实 PTY 交互终端，连续命令保持同一 Shell 状态。
- 终端支持输入、Ctrl+C 中断、动态调整尺寸、复制粘贴、关闭和重新连接。
- 终端会话与脚本运行、工作区保存/上传和运行历史完全分离。

## 可靠性与安全

- 终端会话限制为 8 个，输入、输出和尺寸均有边界，保留原始输出字节。
- WSL 关闭终端时仅清理该会话的进程组，不停止整个发行版。
- 应用退出和自动升级会等待或拒绝活动终端，避免会话资源泄漏。
- 新增 SSH 生命周期、WSL helper、终端状态、缓冲和前端标签测试。

## 验证范围

- 前端测试、TypeScript 检查、Vite 构建、Rust 全量测试和 SSH 本地集成测试通过。
- WSL 终端集成测试已在 Ubuntu-24.04 通过。
- 未使用物理串口设备；串口独立终端仍暂不支持，Serial Shell V1 功能保持不变。
