# Remote Runner v0.5.2

## 新功能

- **系统托盘**：应用常驻 Windows 系统托盘。左键单击托盘图标或托盘菜单「显示主窗口」可唤回窗口；点击窗口关闭按钮（X）现在是最小化到托盘，运行中的任务、终端会话和未保存的编辑全部保留。
- **托盘菜单**：显示主窗口 / 开机自启动（勾选）/ 退出。「退出」会唤回窗口并走未保存确认守卫后真正退出。
- **开机自启动**：托盘菜单与「文件」菜单均可勾选，两个入口状态实时同步。自启动项带静默参数，开机后应用只驻留托盘不弹窗；手动启动仍正常显示主窗口。

## 验证范围

- 前端测试（58 项）、TypeScript 检查、Vite 构建通过；Rust 全量测试通过（新增启动参数解析单测 3 项）。
- 托盘与自启动为桌面平台行为，自动化测试不覆盖注册表写入，需按设计文档 `docs/00018_20260912_tray-autostart.md` 手动验证一次。

## 升级说明

- 安装包可通过应用内「更新」按钮直接升级；便携版请到发布页下载 `Remote.Runner_0.5.2_x64-portable.exe`。
- `latest.json` 与 `.exe.sig` 用于更新校验，无需手动打开。
