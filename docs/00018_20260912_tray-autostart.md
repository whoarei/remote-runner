# 系统托盘与开机自启动设计

版本目标：0.5.2。为 Remote Runner 增加 Windows 系统托盘菜单与开机自启动开关，并把「关闭窗口」语义改为「最小化到托盘」。

## 目标行为

| 场景 | 行为 |
| --- | --- |
| 点击窗口关闭按钮（X）、标题栏关闭 | 隐藏窗口到托盘；运行中任务、终端会话、未保存编辑全部保留，无数据丢失，因此**不触发**未保存守卫 |
| 托盘左键单击、托盘菜单「显示主窗口」 | 显示主窗口、取消最小化并聚焦 |
| 托盘菜单「退出」、应用菜单「文件 → 退出」 | 先显示并聚焦窗口，再走既有退出守卫（未保存确认 → 关闭全部终端 → destroy）真正退出 |
| 托盘菜单 / 应用菜单「开机自启动」勾选 | 两个入口状态一致，切换即时写入系统启动项 |
| 开机自启动生效时 | 以 `--minimized` 参数启动，静默驻留托盘、不弹主窗口；手动双击启动正常显示 |

## 技术选型

- **托盘**：Tauri 2 内置 TrayIcon API（`tauri` crate 开 `tray-icon` feature），全部在 Rust 侧实现，不需要前端权限。
- **开机自启动**：官方 `tauri-plugin-autostart`（内部为 auto-launch crate）。Windows 写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，同时覆盖 macOS（LaunchAgent）/ Linux（XDG autostart），避免手写 winreg。注册启动项时通过插件 `Builder::args(["--minimized"])` 固定附带静默参数。

## 后端设计（`src-tauri/src/tray.rs`）

单一模块负责托盘与启动参数解析，接口：

```rust
pub const MAIN_WINDOW_LABEL: &str = "main";
pub const TRAY_QUIT_EVENT: &str = "tray://quit-requested";
pub const AUTOSTART_CHANGED_EVENT: &str = "autostart-changed";

pub fn start_minimized(args: &[String]) -> bool;   // 纯函数，检测 --minimized，可单测
pub fn setup(app: &tauri::App) -> tauri::Result<()>;
```

`setup` 内容：

1. 构造托盘菜单：`显示主窗口`（MenuItem）、`开机自启动`（CheckMenuItem，初始勾选态取自 `app.autolaunch().is_enabled()`）、分隔符、`退出`。
2. `TrayIconBuilder`：图标用应用默认窗口图标，tooltip 为产品名；左键 `MouseButtonUp` 与「显示主窗口」均执行 `show + unminimize + set_focus`。
3. 菜单事件：
   - `autostart`：读取当前 `is_enabled()`，取反后 `enable()/disable()`，并把结果写回 CheckMenuItem（失败时保持原勾选态并记录日志）。
   - `quit`：`app.emit(TRAY_QUIT_EVENT)`，把退出守卫交给前端既有流程，避免 Rust 侧绕过未保存确认。
4. `app.listen(AUTOSTART_CHANGED_EVENT)`：前端菜单栏切换后同步托盘勾选态，保证两个入口一致。

### 启动即隐藏

`tauri.conf.json` 窗口加 `"visible": false`；`lib.rs` 的 setup 中：

```rust
let main = app.get_webview_window(MAIN_WINDOW_LABEL);
if !tray::start_minimized(&std::env::args().collect::<Vec<_>>()) {
    main.show()?;
}
```

窗口先隐藏创建再由 setup 决定显示，避免自启动时窗口闪一下。

## 前端设计

- `src/autostart.ts` 新增封装：`isAutostartEnabled()` / `setAutostartEnabled(enabled)`（调 `@tauri-apps/plugin-autostart` 的 `isEnabled/enable/disable`，成功后 `emit("autostart-changed", enabled)` 同步托盘勾选态）。
- `src/appLifecycle.ts` 新增 `requestQuit()`：显示并聚焦窗口 → `confirmAllUnsaved()` → `closeAll()` 终端 → `destroy()`；托盘 `tray://quit-requested` 事件与菜单栏「退出」都走这条路。
- `App.tsx` 关闭语义拆分：`onCloseRequested` 一律 `preventDefault()` + `hide()`，不再走守卫。
- `MenuBar.tsx`：「文件」菜单「退出」上方新增 checkbox「开机自启动」，勾选态为组件本地 state（挂载时读一次，切换失败回滚并提示）。

## 权限与配置

- `capabilities/default.json` 增加 `autostart:default`。
- 新增依赖：Rust `tauri-plugin-autostart = "2"`；npm `@tauri-apps/plugin-autostart`。

## 边界与限制

- 托盘「退出」不额外拦截运行中任务，维持既有退出语义（进程退出即终止会话）。
- 开机自启 + 手动启动可能产生第二个实例；如需单实例可后续引入 `tauri-plugin-single-instance`，本次不做。
- 自启动注册表项属于操作系统数据，不在应用配置目录内，卸载时由系统/用户自行清理（NSIS currentUser 安装不处理 Run 键）。
- 无硬件依赖；托盘与自启动为桌面平台行为，自动化验证以参数解析单测 + 手动 `tauri dev` 验证为准。
