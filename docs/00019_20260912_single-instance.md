# 单实例运行设计

版本目标：0.5.4。限制 Remote Runner 同时只能运行一个实例，避免误开多个进程导致串口占用冲突、运行历史/日志并发写入等问题。

## 目标行为

| 场景 | 行为 |
| --- | --- |
| 应用已运行时再次手动启动 | 第二个进程立即退出；已有实例唤起主窗口（取消最小化 + 显示 + 聚焦），与托盘「显示主窗口」语义一致 |
| 应用已运行时自启动项再次触发（`--minimized`） | 第二个进程立即退出；已有实例保持现状，不弹窗打扰 |

## 技术选型

- 官方 `tauri-plugin-single-instance`（v2，Windows 上基于命名互斥锁）。
- 插件在 `tauri::Builder` 上**最先注册**，保证第二实例在初始化其他状态前退出。
- 回调签名 `(app, args, cwd)` 在**已有实例**中执行：
  - `args` 含 `--minimized`（经 `tray::start_minimized` 判定）时不做任何事；
  - 否则调用 `tray::show_main_window(app)`（由私有改为 `pub` 复用，不复制逻辑）。

## 注意

- 开发模式（`npm run tauri dev`）同样生效：重复执行 dev 或手动启动已构建的同名可执行文件都会被拦截。
- 单实例判定基于可执行文件标识，`rr-cli` 是独立二进制，不受影响。
