# Workspace 最近使用记录

- 成功打开工作区后，将目录保存在本机应用的 localStorage 中，重启后仍可通过 Workspace 面板的“选择最近的目录…”下拉框重新打开。
- 最多保存 10 个目录，按最近打开时间排列，相同路径再次打开会移到首位。
- 下拉框始终显示，包含历史目录和“新目录…”选项。“新目录…”打开目录选择对话框，默认定位到当前工作区，没有当前工作区时使用最近的目录。
- 启动时只恢复历史列表，不自动打开目录。重新打开历史目录时会重新读取文件列表；目录不存在或无法访问时显示错误，并保留当前工作区和编辑器内容。
- 此功能上线前使用过的目录没有保存记录，需要重新选择一次。若本地存储不可用，仍可选择工作区，但历史记录无法跨重启保留。
